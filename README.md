# Adaptive Intelligent Mobility System

## Adaptive AI-Driven Intelligent Mobility System for Advanced ADAS and Autonomous Driving

An AI and Robotics-based intelligent mobility platform focused on adaptive multi-sensor perception, sensor reliability, uncertainty-aware risk assessment, Advanced Driver Assistance Systems (ADAS), and autonomous driving.

The system is designed to integrate camera, LiDAR, radar, IMU, and simulated V2X information using CARLA and ROS 2.

---

## Project Ecosystem

This repository provides a shared engineering platform for four connected initiatives:

1. **C2 Capstone**
   - Adaptive AI-Driven Intelligent Mobility System for Advanced ADAS and Autonomous Driving

2. **CSAIR Minor Project**
   - Cognitive Sensor Reliability & Risk Assessment

3. **IndiaNav**
   - Real-world sensor reliability and road-condition perception

4. **Tata InnoVent**
   - ADAS Sensor Reliability Layer

The projects share common perception, sensor fusion, reliability, uncertainty, risk assessment, simulation, and robotics components while maintaining separate experiments and documentation.
